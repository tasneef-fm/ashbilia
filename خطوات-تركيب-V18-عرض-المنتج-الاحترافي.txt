وردة أشبيليا V18 — عرض المنتج الاحترافي

تم بناء النسخة مباشرة فوق V17 الآمنة دون تعديل قاعدة البيانات أو الحضور أو المخزون أو الصلاحيات.

التطوير:
- نافذة عرض كبيرة ومتوازنة على الكمبيوتر والجوال.
- الصورة كاملة بدون قص وبجودة واضحة.
- قسم مستقل لمعلومات المنتج والسعر والتوفر.
- كود المنتج والتصنيف والمورد والوحدة.
- زر إضافة إلى السلة.
- زر مشاركة المنتج.
- زر تكبير الصورة.
- إغلاق واضح وتصميم متجاوب.

التركيب:
1. فك ضغط النسخة.
2. ارفع كل الملفات إلى جذر GitHub بدل الملفات الحالية.
3. انتظر اكتمال GitHub Pages.
4. اضغط Ctrl + Shift + R.

لا يحتاج هذا التحديث إلى SQL.
